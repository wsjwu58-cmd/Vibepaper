当前可调用的 Skill 共 16 个：14 个创作 Skill + 2 个画布执行 Skill。下面是完整的功能级说明与核心指令；省略了内部资源地址、示例调用标识和重复的平台安全条款。

> 这些 Skill 不是固定串行执行。只加载任务需要的 Skill；用户显式指令可裁剪或覆盖 Skill 默认流程，但不能突破工具能力与平台硬约束。

# 一、短剧 / 漫剧类

## 1. 漫剧故事圣经

### 描述

为连续更新的漫剧、动态漫画和 AI 短剧建立稳定、可扩展的故事底座，避免世界观、人物动机和关系前后矛盾。

### 标准输出

- 一句话卖点
- 世界观规则
- 主角与主要配角档案
- 人物关系图文字版
- 核心矛盾
- 主线与三条支线
- 禁止改动的设定
- 前 20 集剧情方向

### 核心指令

- 每个主要角色必须具备：
  - 欲望
  - 弱点
  - 秘密
  - 变化弧线
- 世界规则必须明确代价和边界。
- 设定必须服务剧情，不堆砌无用背景。
- 人物动机保持一致；发生转变时必须展示原因。

------

## 2. 竖屏短剧单集生成

### 描述

生成 1–3 分钟、高密度、适合连续追更的竖屏短剧单集。

### 默认节奏

1. 0–5 秒：直接进入冲突
2. 5–30 秒：升级矛盾
3. 30–60 秒：揭示关键信息
4. 60 秒后：反转或付出代价
5. 结尾：留下强悬念

### 标准输出

- 集数与标题
- 本集目标
- 场景列表
- 完整对白
- 演员动作与情绪
- 镜头提示
- 集尾钩子

### 核心指令

- 不用长篇旁白代替戏剧行动。
- 每集至少有一次冲突升级。
- 反转必须有前置信息，不能凭空出现。
- 台词短、直白、可表演。
- 结尾必须制造下一集观看动力。

------

## 3. 长内容短剧化改编

### 描述

将小说、文章、真实故事或长剧本压缩成高冲突、可连续更新的短剧或漫剧结构。

### 标准输出

- 原作核心卖点
- 保留、合并、删除内容
- 新的主线冲突
- 角色合并方案
- 每集一句话梗概
- 每集开头钩子
- 每集结尾悬念
- 改编风险说明

### 核心指令

- 不机械地按原章节切集。
- 每集完成一个局部事件，同时留下新问题。
- 保留原作核心情感与人物动机。
- 用户提供受版权保护文本时，只依据用户提供的内容改编，不补写未提供的大段原文。

------

## 4. 短剧对白润色

### 描述

在不改变剧情事实的情况下，提高对白的口语感、人物辨识度、潜台词和冲突张力。

### 标准输出

- 原对白问题诊断
- 润色后的对白
- 情绪与停顿标注
- 可删除台词
- 更强冲突版
- 更克制版

### 核心指令

- 不让所有角色使用相同的说话方式。
- 一句台词原则上只表达一个主要意图。
- 优先使用潜台词、动作和反应，不直接解释情绪。
- 保留剧情信息，不擅自改变人物关系和既定事实。

------

## 5. 连续剧一致性审校

### 描述

检查多集短剧、漫剧或连续内容中的逻辑漏洞和连续性错误。

### 检查范围

- 时间线
- 人物动机
- 身份与关系
- 伤势
- 服装
- 道具
- 场景位置
- 角色已知信息范围
- 世界观规则
- 伏笔与回收

### 标准输出







| 问题级别 | 集数/场景 | 问题 | 影响 | 最小修复方案 |
| :------- | :-------- | :--- | :--- | :----------- |
|          |           |      |      |              |

### 核心指令

- 区分真正矛盾、可解释留白和刻意伏笔。
- 优先采用最小改动修复。
- 不为修复一个问题制造新的设定冲突。
- 无法判断时明确标记“需要作者确认”。

------

# 二、角色与连续性

## 6. AI 角色一致性控制

### 描述

为 AI 漫剧、短剧和多镜头生成建立角色视觉规范，降低跨镜头、跨集角色漂移。

### 标准输出

- 角色固定特征
- 可变化特征
- 禁止变化特征
- 正面、侧面、背面描述
- 日常、正式、战斗等服装方案
- 表情与动作词典
- 正向提示词
- 负向提示词
- 每镜头一致性检查清单

### 核心指令

- 固定面部骨相、发型、瞳色、标志物和体型。
- 服装变化必须有剧情原因。
- 每个视频提示词重复核心身份锚点。
- 不使用“漂亮、帅气、有气质”等模糊词替代可观察特征。
- 角色反复出现时，身份描述必须稳定复用，而不是只写“同一个人”。

# 三、脚本与分镜

## 7. 短视频完整脚本

### 描述

将一个主题扩写成可直接拍摄或进入 AI 生成流程的 15 秒至 3 分钟短视频脚本。

### 标准输出







| 时间 | 画面 | 口播/对白 | 字幕 | 音效/转场 |
| :--- | :--- | :-------- | :--- | :-------- |
|      |      |           |      |           |

### 默认流程

核心观点 → 设计钩子 → 拆节奏段 → 生成分镜 → 检查时长与信息密度

### 核心指令

- 前 3 秒必须给出钩子。
- 每 5–8 秒至少发生一次信息、画面或情绪变化。
- 结尾必须明确收束，可自然加入互动引导。
- 口播符合真实说话节奏，不写论文式长句。
- 用户未指定时，默认时长为 60 秒。

# 四、漫画类

## 9. 六格漫画

### 描述

把短场景转化成一张完整六格连环漫画页，而不是六张独立图片。

### 默认规格

- 交付：一张漫画页图片
- 排版：2 行 × 3 列
- 阅读顺序：从左到右、从上到下
- 默认画幅：横版 16:9
- 六格等大
- 细且均匀的分隔线
- 角色外观稳定
- 对白短小
- 全页风格统一

### 六格叙事结构

1. 建立世界和角色
2. 事件启动
3. 行动
4. 复杂化
5. 冲突或误会升级
6. 解决、笑点或余味

### 核心指令

- 默认只生成一个漫画页节点。
- 六个故事节拍必须编译进同一个图片提示词。
- 不默认生成六张单格图后再拼。
- 不做联系表、情绪板或六张无关联插画。
- 人物发型、服装、年龄、标志性道具在每格重复锁定。
- 每格对白最多一至两句。
- 图中文字跟随用户语言。
- 除非用户明确要求可编辑单格，才拆成六张独立素材。
- 如果网格严重错误或角色崩坏，只收紧布局和角色锁定后整页重生成一次。

# 五、海报类

## 10. 极简海报

### 描述

将主题、文章构想、物件或情绪转化为极简编辑海报：大面积留白、做旧纸张、实验性排版和克制但清晰的高纯度色彩锚点。

### 默认视觉规则

- 竖版 3:5
- 70%–90% 为纸张留白
- 主体簇占画面约 8%–25%
- 一个明确图像锚点
- 小号衬线、打字机或等宽字体
- 一句短文案
- 一个高纯度颜色锚点
- 扫描纸张、复印、孔版印刷或旧印刷质感
- 平面正视，不做 3D 海报样机

### 可选构图

- 中央碎片
- 左下漂浮
- 右上色块
- 双面板
- 不规则剪纸
- 字体主导
- 点线环绕
- 单一标本

### 核心指令

- 从复杂内容中提取一个可视觉化的中心隐喻。
- 高纯度色彩必须在缩略图尺度仍清晰可见。
- 一张图只用一个主色锚点。
- 避免商业广告、Logo、CTA、品牌活动感。
- 避免全幅场景、霓虹、3D、电影灯光、卡通、密集拼贴。
- 用户要求出图时，不能只停留在 Prompt，需实际生成图片。
- 结果如果缺少明显色彩锚点，可加强色彩面积后重生成一次。

## 11. 电影海报

### 描述

根据片名、剧情、类型和人物关系设计原创竖版电影海报，包含叙事判断、视觉母题、构图系统和字体系统。

### 默认规格

- 竖版 9:16
- 中文主标题必须清楚可读
- 英文副题只作辅助
- 所有制作署名统一为“VibePaper”
- 不出现真实片商、真实发行方、电影节桂冠或虚假奖项

### 主构成模型

每张只能选一个主要模型，最多一个辅助模型：

1. 电影静帧型
2. 巨型文字结构型
3. 手写字或书法介入型
4. 单一物件隐喻型
5. 极端人物裁切型
6. 负空间小人物型
7. 群像结构型
8. 空间秩序型
9. 监控或第一人称临场型
10. 拼贴、印刷或绘画实验型

### 默认流程

1. 解析类型、冲突、情绪和人物关系
2. 选择一个一级视觉母题
3. 建立构图、色彩和质感系统
4. 设计主标题、宣传语、副题和署名
5. 优先采用底图层、字体层、合成结果的分层流程
6. 输出方案或实际生成海报

### 核心指令

- 先判断电影，再设计海报。
- 不能只是“剧照上加片名”。
- 每张海报只保留一个一级视觉核心。
- 避免人物硬拼贴。
- 参考图仅抽取构图秩序、色彩、密度和字图关系，不复制完整构图。
- 多个编号项目分别生成独立海报，不合成拼图。
- 分层任务应保留底图、字体设计和最终合成结果。
- 字体层由图像模型设计，不用普通系统字体冒充视觉字体。

# 六、电影感画面

## 12. 电影感单图

### 描述

把参考图、简单描述或小段剧情转译成一张具有电影镜头感、明确光影系统和成像取舍的单幅画面。

### 输入模式

- 参考图默认：风格迁移
- 用户明确要求人物、动作、道具、构图不变：完整画面复刻
- 简单描述：补全明确主体、环境、构图和摄影系统
- 小段剧情：选择一个决定性瞬间，不把连续事件全塞进单幅画面

### 默认分析结构

- 画面意图与瞬间
- 风格核心
- 风格来源与视觉转译
- 色调结构
- 光影结构
- 画质取舍与捕捉痕迹
- 摄影与成像
- 主体、环境与构图

### Prompt 四段结构

1. 风格与色调
2. 光影与画质取舍
3. 摄影机、镜头、焦段、光圈、景深与介质
4. 主体、环境和构图

### 核心指令

- 用户指令优先于参考图和 Skill 审美。
- 参考图默认提取风格，不默认复制人物和构图。
- 完整复刻必须由用户明确触发。
- 不自动添加胶片、柔焦、低饱和、抓拍感或前景遮挡。
- 画质损失必须具有物理原因、明确位置和保留锚点。
- 区分：
  - 浅景深
  - 光学柔焦
  - 运动模糊
  - 空气雾化
- 扩散滤镜必须有参考图证据，不能为了“电影感”机械添加。
- 摄影机、镜头、焦段、光圈和景深必须彼此一致。
- 不用于角色卡、白底肖像、三视图、工业 CG 或平面封面。

## 13. 电影感三联图

### 描述

将人物、空间、产品、建筑或小故事转化为三张连续的 21:9 电影画面，像从同一场真实电影中剪出的连续镜头。

### 三镜头职责

1. 建立世界：交代时间、地点、天气和空间秩序
2. 建立关系：角色执行具体动作，事件推进
3. 留下余味：减少信息，以背影、反射、空房、物件或离开的人物收尾

### 默认镜头分配

- Shot 1：24–28mm，人物占画面 5%–15%
- Shot 2：32–50mm，人物占画面 20%–35%
- Shot 3：50–85mm，或改变观察位置，以局部、遮挡和压缩留下余味

### 核心指令

- 默认生成三张独立 2.39:1 图片。
- 不让模型直接生成内置三联拼图。
- 三张图必须属于同一世界、事件、时间、光线和色彩体系。
- 三个镜头不能只是相同场景换角度。
- 至少改变四项：
  - 景别
  - 机位
  - 前景
  - 信息密度
  - 光线集中区
  - 构图骨架
  - 主体与环境比例
  - 情绪密度
- 每个镜头必须有故事动词，如进入、等待、打开、拒绝、发现、离开。
- 反复出现的人物必须使用稳定身份胶囊，重复锁定地域面孔、年龄、脸型、发型、体型、服装和道具。
- 电影感来自机位、调度、光源和空间，不来自“cinematic、epic、8K”等空泛词。
- 每组采用一种主要成像介质，例如：
  - 35mm 放映拷贝
  - 16mm 电视转制
  - MiniDV
  - VHS
  - 长焦胶片压缩
  - 监控或屏幕再拍
- 每张只保留少量有效场景细节，避免 AI 式堆料。
- 至少有一个相对平淡或不完整的过渡镜头，使整组更像真实剪辑。

# 七、人像摄影

## 14. 生命感人像

### 描述

把游客照、生活随拍或普通手机照片升级为鲜活、有亲密距离和真实光感的高级人像，也支持从零生成原创人像样片。

### 三种模式

- 模式 A：普通照片升级
  - 严格保留人物身份、脸、表情、姿态、服装和体型
  - 只改善裁切、光线、肤色、发丝和摄影完成度
- 模式 B：原创样片
  - 默认中国或东亚人物
  - 偏唯美电影化人像
  - 人物、场景、动作和叙事均原创
- 模式 C：普通照片变氛围大片
  - 保留人物、服装、场景和事件
  - 强化光比、景深、色温、背景层次和构图

### 创作优先级

1. 具体人物状态
2. 亲密拍摄距离或特殊机位
3. 前景遮挡与空间层次
4. 大胆裁切与轻微透视
5. 真实硬光、焦散和轮廓光
6. 明亮且和谐的综合色彩
7. 局部失焦、柔光或运动模糊
8. 少量色散、炫光或旋焦

### 核心指令

- 人物必须正在做具体事情，不能只是站着看镜头。
- 生命感来自状态、距离、机位和阳光，不来自滤镜堆叠。
- 每张只使用一种主光学效果和一种轻微辅助效果。
- 面部必须清楚、自然、柔润哑光，不得油亮或塑料化。
- 镜头炫光、色散和焦散不能覆盖主要五官。
- 发丝要轻盈、分离、有空气感。
- 避免同脸换衣、网红模板脸、大眼尖下巴和统一微笑。
- 批量任务中，人物、场景、动作、服装、景别、机位、色彩和光学效果至少七项不同。
- 用户要求 5 张，就生成 5 张独立图片，不做拼图。
- 参考图只提取摄影规律，至少改变五项内容维度，禁止“换个人重演参考图”。

# 八、画布执行类

## 15. Canvas Cookbook

### 描述

不是创作风格 Skill，而是画布复合操作手册。负责把创作方案落实成节点、连线、生成、派生、剪辑、合成和整理。

### 主要工作流

#### 生成

- 图片
- 视频
- 音频
- 文本

#### 派生

- 扩图
- 图片超分
- 视频超分

#### 加工

- 视频剪辑
- 视频抽帧

#### 组合

- 多段视频按输入顺序合成成片

#### 维护

- 素材认证
- 失败阶段重试
- 整体重新生成

#### 整理

- 节点落位
- 依赖图整理
- 分组
- 收纳
- 移动
- 调整连线顺序

### 核心执行指令

- 已知目标、真实节点和参数时直接执行，不先做仪式性读取。
- 缺真实目标才读取或查询。
- 新建生成节点后，只以实际提交结果为准：
  - `queued`：已经开始，不重复提交
  - `skipped`：没有开始，必须查看原因
  - `inputs_not_ready`：等待上游终态后恢复
  - `failed`：说明错误并决定修复或重试
- 异步生成不能用定时器轮询。
- 上游未就绪时，不得宣称下游已完成。
- 新用户指令会停止旧流程自动续跑。
- 用户只要一张图时，只创建一个图片生成节点。
- 手动确认模式下，每次只创建一个媒体生成节点，避免多个生成任务合并成一张确认卡。
- 继续创作时连接上游节点，不复制其历史产物地址作为新输入。
- 视频合成至少需要两段就绪视频。
- 剪辑和抽帧直接从源视频派生，不修改源节点。
- 整理依赖图时遵循“上游在左、下游在右、最终合成最右”的布局。

## 16. DirectorStage 3D 导演台

### 描述

通过 3D 场景中的人物、道具、建筑和机位，预演角色站位、空间关系和镜头构图，并捕获一张 PNG 作为下游图片或视频的构图参考。

### 适用任务

- 人物站位
- Blocking
- 对峙关系
- 道具位置
- 机位设计
- 特殊俯仰角度
- 先建立构图参考，再生成正式画面

### 可用角色与道具

- 人物
- 台阶
- 椅子
- 墙板
- 灯
- 拱门
- 树
- 桌子
- 栅栏
- 方块、球体、圆柱、圆锥等基础几何体

### 人物姿态

- 站立
- 行走
- 奔跑
- 坐姿
- 挥手
- 跳跃
- 点头
- 摇头
- 沮丧
- 潜行
- 儿童姿态

### 机位参数

- 水平旋转
- 俯仰角
- 相机距离

### 核心指令

- 先用导演台确认人物、道具和机位关系。
- 场景或机位修改后自动捕获当前构图。
- 捕获结果可作为下游 Image 或 Video 的参考输入。
- 只有人物模型响应姿态，道具与几何体不响应。
- 修改和删除已有模型前必须读取其真实模型标识。
- 导演台不是最终写实渲染工具，不应用于像素级编辑。
- 如果已有参考图足够，或用户只要最终成图，不必强行经过导演台。
