# VibePaper 产品功能清单

## 一、用户端功能

### 管理空间

#### 画布管理页

- 新建画布

- 导入画布（上传本地 JSON 文件）

- 画布列表展示（预览缩略图）

- 编辑画布名称

- 删除画布

- 下载画布（导出 JSON 文件）

- 删除画布（二次确认弹窗）

#### 画布编辑页

##### 无限画布系统

###### 画布基础操作

- 无限延展的创作空间（不受传统页面限制）

- 画布拖拽 / 平移

- 画布缩放（放大 / 缩小画布大小）

- 适应视图（一键调整画布大小至适应窗口）

- 一键整理（自动排布所有内容）

- 鼠标模式切换（选择模式 / 抓手模式）

##### 卡片（节点）管理

- 新建卡片（3 种方式：左侧添加按钮 / 右键画布 / 双击画布空白处）

- 卡片拖拽移动

- 卡片缩放

- 卡片复制

- 卡片删除

- 多卡片框选

- 卡片编辑（修改内容、参数）

##### 连线系统

- 添加连线（左侧输入节点 ← 右侧输出节点，建立上下游引用）

- 通过输出节点呼出模态选择列表，一键创建下游节点

- 删除连线

- 连线状态可视化（蓝色 = 有效 / 灰色 = 无效 / 黑色 = 选中）

##### 编组功能

- 框选多卡片 → 编组

- 编组颜色选择

- 网格排列（编组内卡片自动网格布局）

- 水平排列（编组内卡片自动水平布局）

- 取消编组

- 下载编组内所有内容

##### 堆叠功能

- 框选多卡片 → 堆叠为一张卡片（展示拼图预览）

- 双击展开堆叠卡片

- 点击空白区域重新堆叠

- 拉出到画布（将堆叠中某张卡片单独拉出）

- 参数选择（分辨率、风格、份数）

- 消耗预览

- 生成历史列表

##### 视频卡片

- AI 生成视频（调用模型）

###### 视频编辑操作

- 剪辑（拖动首尾边界，确认时间范围）

- 提取帧（拖动时间轴，截取当前帧）

- 超分（选择目标分辨率）

- 认证（上传至 Seedance 2\.0 素材库认证）

- 下载到本地

- 存入素材库

- 全屏展示

- 模型选择（视频生成模型切换）

- 参数选择（运镜、风格、份数）

- 消耗预览

##### 音频卡片

- 上传参考

- AI 生成音频

- 存入素材库

- 模型选择

- 消耗预览

- 参数选择（风格、份数）

##### 生成增强功能

###### 合成节点

- 左侧接收多个视频节点输入

- 多段视频拼接预览

- 点击「合成」完成拼接

- 消耗预览

###### 导演台

- 作为图片 / 视频节点的上游输入（精确指导人物站位与动作）

- 进入导演台编辑页面

- 新增模型（从模型列表选择添加）

- 修改模型参数（场景 / 基础模型位置与大小、人物模型颜色 / 位置）

- 拖拽滚轴调整参数

- 删除模型

- 拍照（生成当前场景截图作为输出）

- 调整视角

##### 个人素材库

- 素材库侧边栏展示

- 图标模式 / 列表模式切换

- 从画布卡片存入素材库

- 本地文件上传至素材库

- 长按拖拽素材到画布（菜单操作）

- 导入画布

- 下载素材

- 替换素材（上传新文件替换）

- 删除素材

- 重命名素材

- 全屏预览素材

- 从个人素材库添加到团队素材库

##### Agent 对话系统

###### 对话交互

- 自然语言驱动画布创作

- 实时理解画布上下文（读取当前画布内容、节点关系、用户操作）

- 全流程自动创作（灵感发散 → 资料整理 → 内容生成 → 结构排版）

- 多次对话持续创作

- 创作建议

###### 对话操作

- 打开 Agent 对话框（右下角纸鹤图标）

- 收起 Agent 对话框

- 偏好设置（选择文本模型 / 图片模型 / 视频模型 / 分辨率）

- 查看当前对话用量（token 总量、各模型消耗量、点数消耗）

###### Skill 系统

- Skill 选择入口

- 预设 Skill 列表浏览

- 按名称 / 描述搜索 Skill

- 单击选中 Skill 添加到对话

###### 新建 Skill（3 种方式）

- 空白创建（名称 \+ 描述 \+ 指令 → 保存）

- 从当前对话生成（Agent 自动总结 → 检查修改 → 保存）

- 上传 Skill 文件（选择本地\.md 文件上传）

- Skill 管理与切换

- Skill 内容查看

###### 对话历史

- 查看当前画布对话历史

- 查看其他画布对话历史

- 新建对话

- 保存会话片段（保存到可复用对话历史，支持多画布复用）

###### 记忆系统

- 短期记忆：理解当前 session 创作上下文

- 长期记忆：记录用户偏好（表达风格、内容方向、创作习惯）

##### 订阅菜单

- 查看用户名、id、个人点数和总可用点数

- 设置界面亮暗主题和中英文

- 查看个人订阅方案

- 订阅个人方案

- 购买点数

- 查看企业方案优势，获取顾问联系方式

##### 分享画布

- 生成共享链接，管理共享状态

- 上传到创意工坊

##### 奖励中心

- 每日签到

- 查看每日任务和完成状态

##### 邀请中心

- 查看我的邀请码和邀请链接

- 查看我的邀请人数

- 输入邀请码接受邀请

- 查看成功邀请记录

- 查看指南

- 反馈建议

- 显示当前画布

##### 历史记录

- 查看所有画布的生成任务执行记录

- 记录字段：时间 / 结果缩略图（可展示） / 模态 / 模型 / 花费点数 / 提示词

- 按提示词搜索

- 按模型搜索

- 按模态筛选

- 按状态筛选

- 按时间范围筛选

- 重置

- 刷新

- 复制提示词

##### 创意广场

- 浏览站内公开画布作品

- 成品预览（上下切换）

- 查看画布制作过程（节点流程图）

- 一键克隆画布到个人工作区

- 灵感发现与模板复用

- 搜索

- 全屏观看

- 删除自己上传的作品

##### 个人中心

- 点数消耗情况总览

- 账户身份信息

- 当前剩余点数

- 每日签到入口

- 退出登录

- 界面设置

### 企业中心（团队协作）

##### 企业邀请

- 分配记录统一管理

##### 分配记录

- 操作后账户余额

##### 用量统计

- 企业用量 / 个人用量切换查看

- 按时间范围筛选

- 点数消耗可视化

- 修改企业名称
